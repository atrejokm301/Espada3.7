En PC: Comentario / Diccionario / Léxico usan una columna derecha con módulos que tienen contenido (●) para el versículo o lema.
Formato en todos los temas
• Títulos y encabezados: más grandes y subrayados
• Solo el número del versículo va subrayado (no todo el texto)
• El primer versículo de cada capítulo se ve un poco más grande
• Palabras de Jesús: siempre en rojo (si el módulo las marca)
• Resaltados: clic derecho → Resaltar (colores por nombre, se adaptan al tema)
• Subrayar / Copiar / Compartir: mismo menú contextual suave
• Alto contraste para lectura cómoda
